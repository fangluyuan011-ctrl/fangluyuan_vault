# 1.通用文件分析类

| 工具           | 用途                                    | 典型命令                          |
| -------------- | --------------------------------------- | --------------------------------- |
| file           | 识别文件真实类型（不依赖扩展名）        | file suspicious.jpg               |
| strings        | 提取可打印字符，查找可疑文本            | strings -n 8 hidden.jpg           |
| exiftool       | 读取/写入文件元数据（EXIF、备注）       | exiftool image.png                |
| binwalk        | 检测文件中嵌入的其他文件（固件/多文件） | binwalk -e file.jpg               |
| foremost       | 文件雕刻，分离出嵌入的文件              | foremost -i file.jpg -o output/   |
| xxd            | 十六进制查看，手工分析文件头尾          | xxd file.jpg                      |
| bulk_extractor | 扫描磁盘镜像中的邮件、URL、图片等       | bulk_extractor -o output image.dd |

# 2. 图像隐写工具

| 工具           | 适用场景                               | 用法示例                                              |
| :------------- | :------------------------------------- | :---------------------------------------------------- |
| `steghide`     | LSB隐藏，支持密码爆破                  | `steghide extract -sf image.jpg -p secret`            |
| `stegseek`     | 高速爆破 steghide 密码                 | `stegseek image.jpg /usr/share/wordlists/rockyou.txt` |
| `stegsolve`    | 图像平面分析（色道、LSB、位运算）      | 图形化工具，加载图片逐帧查看                          |
| `zsteg`        | PNG/BMP 的 LSB 及多种格式分析          | `zsteg -a image.png`                                  |
| `stegoveritas` | 全能型，支持图像、音频、元数据         | `stegoveritas image.png`                              |
| `outguess`     | 针对 JPEG 的 LSB 隐藏                  | `outguess -k "key" -r image.jpg output.txt`           |
| `jsteg`        | JPEG JSteg 算法提取                    | `jsteg reveal image.jpg output.txt`                   |
| `f5`           | F5 算法（JPEG 高频嵌入）               | `f5 -t -i f5.jpg -o extracted.txt`                    |
| `stegdetect`   | 检测 JPEG 是否被 JSteg/OutGuess 等隐藏 | `stegdetect *.jpg`                                    |

# 5. 文本与网络隐写

| 工具       | 说明                                        |
| :--------- | :------------------------------------------ |
| `sn0int`   | 半自动化 OSINT，但能处理图片中的地理位置等  |
| `stegosip` | 检测/提取基于 TCP/IP 协议头的隐写（需安装） |
| 正则表达式 | 手工查找 Base64、十六进制串等异常文本       |

1. **识别真实类型**：`file` + `binwalk`，判断是否单纯图片或复合文件。
2. **提取元数据**：`exiftool` 查看备注、作者、GPS，可能有直接密码或提示。
3. **搜索字符串**：`strings` + `grep` 寻找 flag 格式或密码。
4. **文件雕刻**：`binwalk -e` 和 `foremost` 分离隐藏的 ZIP、RAR、图片等。
5. **按类型选择专用工具**：
   - PNG/BMP → `zsteg -a`，`stegsolve`
   - JPG → `steghide` + `stegseek`，`outguess`，`jsteg`，`f5`
   - 音频 → `Audacity` 看频谱，`Sonic Visualiser`
6. **密码爆破**：如果 `steghide` 需要密码，用 `stegseek` 或 `stegbreak`。
7. **通用扫尾**：`stegoveritas` 一键尝试多种方法。

# 工具速查表

| 分类      | 工具                                        | 核心用途                         | 一句话口诀                      |
| :-------- | :------------------------------------------ | :------------------------------- | :------------------------------ |
| 基础分析  | `file`, `exiftool`, `strings`               | 识别类型、查看元数据、提取字符串 | 查类型、看信息、找文本          |
| 文件提取  | `binwalk`, `foremost`                       | 分离嵌入文件                     | 分离隐藏的压缩包或图片          |
| 图像LSB   | `zsteg`, `stegsolve`, `stegoveritas`        | PNG/BMP 的 LSB 提取              | 逐位逐色看，zsteg 一把刷        |
| JPEG 隐藏 | `steghide`, `stegseek`, `outguess`, `jsteg` | JPEG 常见隐写                    | 有密码就爆破，没密码就 outguess |
| 音频分析  | `Audacity`, `Sonic Visualiser`              | 查看频谱、波形                   | 打开频谱找密码，Audacity 是法宝 |
| 自动化    | `stegoveritas`, `stegseek`                  | 多方法自动尝试                   | 拿不准时用                      |
